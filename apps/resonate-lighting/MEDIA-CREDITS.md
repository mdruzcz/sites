# Media credits — resonatelighting.com

## Current state (2026-10-21)

**No third-party photos, videos, illustrations or audio are used on this site.**

Every visual is generated by the site's own code:

| Visual | Source |
|---|---|
| Mega tree, roofline house, wrapped deciduous tree, evergreen spirals, pixel arches, town-square layouts | Rendered live in the browser by `src/lib/lightshow/` (props built in code, drawn on `<canvas>`) |
| Light patterns, themes, colour schemes and music looks | Ported from Resonate's own Light Show app (`Xlights/showui/tree.js` and `index.html`) |
| Piano and drum sounds in the demo | Synthesised at runtime with Web Audio oscillators and generated noise (`src/lib/lightshow/live.ts`); no samples |
| Logo, mark, favicons, OG image | Resonate brand kit in `brand/` |
| Signal-chain diagram and icons | Inline SVG/HTML in the components |

No images or videos were copied from any other company's website.

## Adding media later

- **Your own photos and videos:** set `src` on the matching slot in `src/content/media-slots.json` (each slot's `note` says what belongs there) and put the file in `public/media/`. Slots without a file show a labelled 3D render.
- **Stock media:** only Pexels, Unsplash or Pixabay items under their free licences. Before using one, add a row below with the page URL, the photographer, the licence and where it is used. Prefer our own renders and photos.
